# JabangStore — No-VS-Code Workflow

This version is designed around:

1. GitHub — source code repository
2. Supabase — database, authentication, storage and security
3. Vercel — web deployment/hosting

The founder/user is not required to install or use VS Code as part of the normal workflow.

Important: JabangStore remains a real React + TypeScript + Vite application. It is not intended to be reduced to a single static HTML file.

Use the updated master build prompt as the permanent product/build specification.
